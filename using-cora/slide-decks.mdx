You can get a deck two ways: a **native presentation** on [Artifacts](/using-cora/artifacts), or a **Google Slides** copy in Drive.

## Native presentations

Ask Cora in chat for a presentation or QBR deck. Cora saves it as a Presentation artifact.

Chat shows a preview. Reopen it from **Artifacts** with the **Presentation** filter, then **Present** from the player.

You do not need a Google Drive connection, and you do not share a file with Cora first.

You cannot pin a presentation to **Analytics**; that stays dashboards.

### Reuse a deck as a template

Mark a presentation as a template on [Artifacts](/using-cora/artifacts#templates) and Cora builds new decks from it. Ask in chat, for example:

_"Build the Globex QBR from our QBR template."_

Cora copies the template, keeps its design, and changes only the text. Anything it has no data for stays a labeled placeholder you can fill in. Agents running on your accounts can do the same with your templates, and they never change the original.

Google Slides files can't be marked as templates. For those, use the Google Slides steps below.

## Google Slides

Cora turns any Google Slides file you bring into a finished deck, filled with your account data and edits. It always works on a copy, so your original is never changed.

Cora fills a deck two ways, and you can combine them in one deck:

- **Placeholders**: Cora fills names in `{{ }}` braces, like `{{company_name}}` → AcmeCorp
- **Text swaps**: Cora replaces exact text already in the deck, like **Jan 1, 2026** → June 22, 2026

### Placeholders or text swaps

Placeholders give the most consistent results, because Cora fills each one by name.
Use them in a template you build for Cora, especially one an agent fills on every run.

Text swaps work on any deck, including last quarter's finished deck.
Cora reads the deck first, then replaces the exact text you point it to.
Matching is exact, including capitalization, so pick distinctive text: swapping **2024** changes every place it appears.
A swap can't span two text boxes or table cells.

Only `{{ }}` braces are placeholders.
Text in other brackets, like `[Customer Name]` or `<<name>>`, is filled as a text swap and stays as written when Cora has no value for it.

Filled text takes the style of the placeholder's first character, so format the placeholder the way you want the value to look.
Cora fills plain text: line breaks work, but Markdown like `**bold**` shows up literally.

### Removing optional slides

When an agent fills a deck, Cora deletes every slide that still has an unfilled `{{ }}` placeholder.
Use this to include a slide only when it applies, like a product slide the customer didn't buy.

In chat, Cora never deletes slides.
Unfilled placeholders stay visible so you can see what still needs a value.

To make a slide optional:

1. Add a placeholder to the slide, like `{{if_purchased_lifecycle}}`, in a text box on the slide (not the speaker notes).
2. In the agent's instructions, tell it to fill that placeholder with empty text when the slide applies. That clears the placeholder and keeps the slide.
3. Tell it to leave the placeholder out when the slide doesn't apply. Cora deletes the slide.

<Warning>
  Any unfilled placeholder deletes its whole slide, including one the agent had no value for or one with a misspelled name. If a slide must always stay, tell the agent to fill every placeholder on it, with a fallback like **TBD** when a value is missing. Text that uses `{{ }}` braces for another reason also deletes its slide.
</Warning>

Slides are only removed when the agent fills at least one placeholder in that run, so a deck filled only with text swaps never loses slides.
Cora removes whole slides, not part of a slide.
To blank out a section, have the agent fill its placeholder with empty text; the text box itself stays.

### Creating a deck

Before you start, make sure:

- [ ] Google Drive is connected in **Settings → Integrations**
- [ ] Your deck is a Google Slides file (convert an uploaded PowerPoint first)
- [ ] It's shared with [**cora@cora.ai**](mailto:cora@cora.ai) (directly, or via **"Anyone with the link"** sharing). Viewer access is enough (Editor only if your organization blocks copying for viewers)

Then:

<Steps>
  <Step title="Share your deck in chat">
    In Cora chat, paste the link and tell Cora how to fill or edit the slides. It reads the deck and your account data to make the changes.
  </Step>
  <Step title="Open the finished deck">
    Cora returns a link to the finished deck.
  </Step>
</Steps>

Some workspaces have a template built into a Cora skill (for example, an EBR master deck), so there you skip the link and just prompt Cora. To learn how skills work and how to build your own, see [How to Build Skills](/agents/how-to-build-skills).

### How the finished deck is shared

Cora shares every deck it creates automatically:

- **Anyone in your organization** can edit it
- **Anyone with the link** can view it

The deck is a new copy, so your original is never changed. It opens from the link Cora gives you and is owned by Cora's [**cora@cora.ai**](mailto:cora@cora.ai) account. Use **File → Make a copy** to save it to your own Drive.
